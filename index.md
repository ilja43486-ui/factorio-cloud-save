# Factorio Cloud Save

Factorio Cloud Save is a small desktop helper for a private group of friends who play one Factorio world in turns. It uploads and downloads the game's save files and mods to a shared Google Drive folder owned by the players.

Factorio Cloud Save - небольшая программа для компании друзей, которые по очереди играют в один мир Factorio. Она выгружает и скачивает сейвы и моды игры в общую папку на Google Диске самих игроков.
